# Character Manager — TP3 (Java Visual SIH-6406)

## Deskripsi

Character Manager merupakan program Java yang dirancang untuk mengelola objek karakter game dengan menerapkan konsep Object-Oriented Programming (OOP). Pada TP3 ini, program mengimplementasikan class, constructor, encapsulation, enum, getter dan setter, serta method untuk meningkatkan level karakter.

Program ini juga dikembangkan melalui Mini-Challenge dengan menambahkan atribut mana, validasi mana, method `isAlive()`, dan pembaruan `toString()` untuk menampilkan informasi karakter secara lengkap.

## Fitur

- Menggunakan package `com.unpri.charactermanager.model`.
- Mengimplementasikan `CharacterType` menggunakan enum.
- Menggunakan dua constructor pada class `Character`.
- Menerapkan encapsulation melalui atribut private.
- Menyediakan getter dan setter.
- Mengimplementasikan validasi level dan mana.
- Mengimplementasikan method `levelUp()`.
- Mengimplementasikan method `isAlive()`.
- Menampilkan informasi karakter melalui `toString()`.
